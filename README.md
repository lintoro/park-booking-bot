# 遊樂園團體預約 LINE 官方帳號智慧自動化系統 (LINE OA Reservation Bot)

本專案為遊樂園團體預約打造之輕量、穩定且具備防呆機制的 LINE 官方帳號 (LINE OA) 智慧預約與排程系統。

---

## 專案設定與目錄結構

* **專案工作目錄**：`C:\Github\ReactApp\LineBot_test`
* **企劃參考來源**：`參考資料勿上傳/遊樂園團體預約LINE智慧自動化_專案企劃書.md`

### 核心技術選型決策紀錄
1. **初期採用 Python (FastAPI / LINE Bot SDK v3)**：
   * 邏輯簡潔、狀態機與防呆條件直觀。
   * 與 Google Calendar / Google 試算表（Google Sheets）等資料庫串接成熟。
   * 未來若需加入 AI 大語言模型（自然語言意圖理解、語音訂位等）生態最豐富。
2. **未來切換 Node.js 之低成本架構設計**：
   * LINE Flex Message 卡片採獨立 JSON 模板管理，與程式語言解耦。
   * 預約業務邏輯與 Webhook 路由分離，便於日後 1:1 遷移。

## 核心營運規範與防呆規則摘要

1. **園區承載量管制**：
   * 全日上限：1,000 人。
   * 上午場次（10:00～13:00）：上限 400 人。
   * 下午場次（13:00～17:00）：上限 600 人。
   * 梯次間隔：每 30 分鐘為一梯次。
   * **截止入場防呆**：17:00 以後一律不開放團體預約。
2. **成團門檻與當日急單**：
   * 最低 **20 人** 成團（未滿 20 人自動導向散客通路）。
   * 當日預約急單：
     * 上午送單：僅能預約 13:00 以後下午場。
     * 下午送單：僅能預約 15:00 以後（15:00～17:00）。
3. **票價與隨隊優惠**：
   * 全票：NT$ 280 元 / 人。
   * 半票（7~12 歲、65 歲以上）：NT$ 140 元 / 人。
   * 幼童免票（6 歲以下）：NT$ 0 元。
   * **遊覽車隨隊優惠**：每 1 台遊覽車，贈送 1 司機 + 1 領隊免票（共 2 位免票，不計入金額）。
4. **訂金政策**：
   * 門票總額之 **10%**（已付訂金＝保證保留；未付訂金＝意向登記，額滿可取消）。
5. **八步驟對話式預約流程 (Conversational Intake)**：
   * Step 0: 啟動（關鍵字 / 圖文選單）
   * Step 1: 團體/學校/公司名稱
   * Step 2: 聯絡人姓名與手機
   * Step 3: 入園日期與時段（驗證急單與時段上限）
   * Step 4: 各票種人數（檢驗 $\ge$ 20 人）
   * Step 5: 遊覽車台數（計算免票額度）
   * Step 6: 統編與發票抬頭
   * Step 7: 生成 Flex Message 核對確認卡與費用試算
   * Step 8: 正式確認送出 $\to$ 寫入試算表/資料庫並通知管理群組
6. **防呆與真人接手**：
   * 15 分鐘未回應對話自動重置。
   * 輸入「專人」、「客服」、「業務」、「電話」等關鍵字立即暫停機器人並送出專人聯絡名片。
